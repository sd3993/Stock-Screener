# S1: run setup and holdings (scripts; both modes)

`python -I tools/scripts/run_setup.py <FYyyQn> --mode full|recheck` (to write; `runs/new_scripts_spec.md`) does steps 1-3; until it exists, a light-tier helper does them from this file. Step 4 is a script the orchestrator starts; it passes the script's messages to the user.

1. **Run folder:** create `runs/<FYyyQn>/` (the latest ended quarter; a second run in the same quarter gets `_full`, `process/README.md`, "Run folders") with `progress.md` (first line `Mode: full` or `Mode: recheck`, then the claim line and checklist, per `process/README.md`) and an empty `status.csv` (header `sym,phase,state,stage,loops_to_s10,results_used,updated,note`). Set `RUN` in `tools/scripts/config.py`.
2. **Recheck mode only:** copy `sector_map.md`, `sectors.json` and `sector_of.tsv` from the last full run's folder (the newest whose `progress.md` says `Mode: full`) into the run folder, and note which run they came from in `progress.md`.
3. **Sheet:** create the tab "Pending <FYyyQn> results" (replacing the previous quarter's; only one exists) and put its name in Data!BA1, through the `gws` CLI (`tools/tools.md`, "Google Sheets (`gws` CLI)") (layout: "The sheet").
4. **Holdings:** run `python tools/scripts/kite_holdings.py` (Kite CLI; writes the same holdings to `data/kite/holdings.csv` and the sheet's Holdings tab, `tools/tools.md`, "Holdings script") and copy `data/kite/holdings.csv` to `<run>/holdings.csv`. Pass on to the user any line it prints starting "SHEET NOT UPDATED", "NO FREE ROW" or "sold:". If it exits 3 (not logged in), ask the user to run `kite auth login` with the warning in `COMMON_AI.md`; if they aren't available (an unattended run), run `python tools/scripts/kite_holdings.py --latest <run>/holdings.csv` (writes the newer of the local file and the sheet), tell the user the date it prints, and carry on.
5. Holdings skip S3's rejects and S8's gate and always go on to S9, so they run through the full analysis (full mode) or the marker check (recheck mode) with fresh figures.
