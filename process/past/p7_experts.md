# P7: expert evidence (one Opus medium helper; web)

Find India-specific multibagger evidence from proven, named practitioners and research houses, for example Motilal Oswal's annual Wealth Creation Studies, Marcellus (Saurabh Mukherjea), Christopher Mayer's 100-baggers work and Thomas Phelps, Vijay Kedia, and IIM Ahmedabad's Indian factor data. Use WebSearch and WebFetch; prefer the original report to news coverage.

For each finding: the claim, the evidence behind it (sample, period, method), the source (person or firm, title, date, link), and whether it holds in India specifically. Note where sources disagree.

Write `runs/past/<date>/experts.md`:
- findings, grouped by theme (growth, valuation, quality, size, management and ownership, business type, exits);
- testable hypotheses H1-Hn for P3.4, each stated as a point-in-time feature with a threshold and the horizon it targets;
- any expert citations in `process/investing_rules.md` that the sources don't support, with the correct reading. These go into `proposals.md` for the user; the rules file isn't edited here.

On a re-run, update the existing file: add newer editions and studies, and keep the hypothesis numbers stable.
