# P3.1-P3.3: statements for the sample (scripts, run by the orchestrator)

**P3.1:** normally already done by P1.2's single fetch (`p1_sample.md`, "Order"); then P3.1 only checks that every `sample.csv` company has its files and fetches any that don't. For every company in `sample.csv`:
`uvx --from screener-mcp==0.5.0 python tools/scripts/scr_company.py <SYM> --only statements,quarterly,shareholding,overview,documents,announcements,nse`
(no login, no model tokens; run them in a loop in the background, paced, and skip companies whose `scr/` is fresh from this study run).

This gives about 12 years of annual statements (consolidated and standalone), 13 quarters, 12 quarters of shareholding and pledge (`shp_history.json`), the annual-report list with exchange links back to about 2013, and NSE announcements.

Record in `status.md` the companies fetched and any failures with the reason. BSE-only companies have no NSE announcements or insider feed; the script saves an empty marker for them (`nse_listed: false`), so they aren't failures and `--skip-saved` doesn't ask again. No step needs them. **P3.2:** then the older shareholding the features need (the latest pattern filed by each start date and the 12 quarters before it, Mar 2001 - Jun 2022) comes from BSE: `python -I tools/scripts/bse_shp.py` (plain curl, resumable; `--plan` counts requests; usage in `tools/tools.md`, BSE). It needs each company's BSE code from `scr/overview.json`, so run it after the fetch above; it reports companies without one. **P3.3:** statements for the years before screener's (P3.4's features look back up to 6 years from each window start) come from the annual reports: `python -I tools/scripts/ar_statements.py plan` (needed years from `sample_candidates.csv`; default groups winner and fallen_winner, `--groups control` once controls are chosen), `fetch` (resumable; screener's annual-report links, then BSE link patterns; keeps the statement pages' text and a parsed JSON per report, deletes the PDF), then `queue`: `ar_missing.csv` (no report found by link: a P4 browser helper (CLAUDE.md, "Browser fetches") collects their links from BSE's annual-report list into `ar_links.csv` (sym, fy, url) in the run folder; the orchestrator re-runs `fetch`, which tries those first) and `ar_helper_queue.csv` (fields the parser couldn't read with confidence, in groups of about 25 reports, for P4 fallback helpers, Sonnet low, briefed by `p4_ar_helper_brief.md`). After a parser fix, `reparse` re-reads the saved pages without downloading. Other older filings for the stage studies (P6) are read from BSE/NSE documents there, not fetched here.
