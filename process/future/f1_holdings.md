# F1: run setup and holdings (orchestrator)

1. **Run folder:** create `runs/future/<FYyyQn>/` (the latest ended quarter) with `progress.md` (claim line and checklist, per `process/future/README.md`) and an empty `status.csv` (header `sym,phase,state,stage,loops_to_f7,results_used,updated,note`). Set `RUN` in `tools/scripts/config.py`.
2. **Sheet:** create the tab "Pending <FYyyQn> results" (replacing the previous quarter's; only one exists) and put its name in Data!BA1, through the `gws` CLI (`tools/tools.md`, "Google Sheets (`gws` CLI)") (layout: "The sheet").
3. **Holdings:** run `python tools/scripts/kite_holdings.py` (Kite CLI; writes the same holdings to `data/kite/holdings.csv` and the sheet's Holdings tab, `tools/tools.md`, "Holdings script") and copy `data/kite/holdings.csv` to `<run>/holdings.csv`. Pass on to the user any line it prints starting "SHEET NOT UPDATED", "NO FREE ROW" or "sold:". If it exits 3 (not logged in), ask the user to run `kite auth login` with the warning in `CLAUDE.md`; if they aren't available (an unattended run), run `python tools/scripts/kite_holdings.py --latest <run>/holdings.csv` (writes the newer of the local file and the sheet), tell the user the date it prints, and carry on.
4. Holdings skip F3's rejects and F4's gate and always go on to F6, so they run through the full analysis with fresh figures.
