# S1: run setup and holdings (scripts; both modes)

`python -I scripts/run.py setup <FYyyQn> --mode full|recheck` (add `--suffix _full` for a second run in the same quarter) does steps 1-3 (rules and refusals in `run.py setup --help`); if it prints a line starting "SHEET NOT UPDATED", the local part is done: fix the sheet access and run it again with `--sheet-only`. Step 4 is a script the orchestrator starts; it passes the script's messages to the user.

1. **Run folder:** create `runs/<FYyyQn>/` (the latest ended quarter; a second run in the same quarter gets `_full`, `/workflow/WORKFLOW.md`) with `progress.md` (first line `Mode: full` or `Mode: recheck`, then the claim line and checklist, per `/workflow/orchestrator.md`) and an empty `status.csv` (header `sym,phase,state,stage,loops_to_s10,results_used,updated,note`). Set `RUN` in `scripts/config.py`.
2. **Recheck mode only:** copy `sector_map.md`, `sectors.json` and `sector_of.tsv` from the last full run's folder (the newest whose `progress.md` says `Mode: full`) into the run folder, and note which run they came from in `progress.md`.
3. **Sheet:** the pending tab (sheetId 105; only one exists) is renamed "Pending <FYyyQn> results" and its rows cleared (kept as is when it already has that name), and its name goes in Data!BA1, through the `gws` CLI (access and layout: `/sources/sheet.md`). Renaming keeps its sheetId, which `/sources/sheet.md` names.
4. **Holdings:** run `python scripts/kite_holdings.py` (Kite CLI, read-only per `/sources/kite.md`; writes the same holdings to `data/kite/holdings.csv` and the sheet's Holdings tab, `/sources/kite.md`) and copy `data/kite/holdings.csv` to `<run>/holdings.csv`. Pass on to the user any line it prints starting "SHEET NOT UPDATED", "NO FREE ROW" or "sold:". If it exits 3 (not logged in), ask the user to run `kite auth login`; if they aren't available (an unattended run), run `python scripts/kite_holdings.py --latest <run>/holdings.csv` (writes the newer of the local file and the sheet), tell the user the date it prints, and carry on.
