# S14.0: listing, a batch of agreed analyses (scripts; both modes)

Copies each agreed analysis in the batch into the Google Sheet "Stock Screener" (`1yBV2fZiIR9xgZ3r-5feDKF_urqXspkPLLG9wPDoPtDU`) and the verdict history, by script through the `gws` CLI (access and layout: `/sources/sheet.md`). No analysis; values are copied exactly; formula columns are never written. The agreed analysis of a company is the highest `recheck<N>.json` in its newest results-quarter folder `runs/companies/<SYM>/<FYyyQn>/`. The orchestrator runs, from the project root:

0. **Thesis register:** `python -I scripts/thesis.py register <SYM>...` copies each agreed analysis's horizon, stage, results used, basis and markers into `runs/companies/<SYM>/thesis.json` (the previous version kept in its `history`). A company it refuses (marker rules in `thesis.py register --help`) goes back to its analysis recheck and is not listed.
1. **Prices:** `uvx --from screener-mcp==0.5.0 python scripts/scr_company.py <SYM>... --only overview` (screener's current price, the sheet's stored fallback price, and the NSE/BSE codes; if screener.in can't be reached: `/principles/access_rules.md`).
2. **Listing:** `python -I scripts/sheet_write.py listing <SYM>... [--hold <SYM>...]` (the `--hold` companies are S11 `hold`s in recheck mode: a verdict-history row only, "markers held, results <FYyyQn>"). Per company it writes (columns BE and BF exist only once the sheet change in `/sources/sheet.md` is applied; until then use `--dry-run`):
   - **Data tab** (sheetId 106): its row found by ticker in column A (else the first empty row; none: "NO FREE ROW", exit 3), only these columns: A Ticker, B Google code (`NSE:<symbol>`, or `BOM:<bse code>` for BSE-only companies), C Screener URL (`https://www.screener.in/company/<SYM or BSE code>/consolidated/`), D Name, E Sector, F Results used, G Analysis date, H Stored price, I EPS TTM (normalised), J Base EPS y1, K Short horizon (Y/N), L Short base EPS y2, M Short bear EPS y2, N Short exit P/E, O Medium horizon (Y/N), P Medium base EPS y5, Q Medium bear EPS y5, R Medium exit P/E, S Long horizon (Y/N), T Long base EPS y7, U Long bear EPS y7, V Long exit P/E, W Dividend/share/year, X Evidence quality, Y Non-negotiables (Pass/Bent/Fail), Z Bent rules, AA Thesis, AB Kill condition and review date, AC Analysis file, BB Closest horizon (the analysis's `horizon` when `horizon_holds` is false, else blank), BC Non-negotiables failed (names), BE Horizon, BF Stage. K, O and S: Y only in the column of the analysis's `horizon`, and only when `horizon_holds` is true; N in the other two (one horizon per position, so the company lists on one horizon tab). EPS and exit-P/E cells stay blank for horizons the analysis gives no figures for.
   - **Data Flags tab** (sheetId 10): each listed ticker's old rows replaced by one row per data flag in its analysis (A Ticker, B #, C Item, D What disagreed, E Values seen, F Value used and why, G Type), the tab sorted by ticker.
   - **Pending results tab** (its name in Data!BA1): the company added (A Ticker, B Name, C Latest declared quarter, D Results due by, E Notes) when its results_used is earlier than the run quarter, removed otherwise.
   - **Verdict history:** one row in `runs/verdict_history.csv`: date, run folder, sym, results used, verdict (horizon, or the closest horizon with "horizon test fails" for a holding, stage, and non-negotiables overall), reason (the analysis's `what_changed`, else first listing / changed from the previous verdict / unchanged on newer results).
   - **Read-back:** every written range is read back and compared cell by cell; a difference is rewritten once, then the script fails (exit 4) naming the cells. Tell the user about any failure.

If the script can't write (gws auth lapsed, the sheet layout not yet changed): `sheet_write.py listing ... --dry-run` saves the exact write plan (`<run>/sheet_plan_listing_*.json`: every range and its values); a light-tier subagent applies it with `gws` (RAW), reads every range back and compares it cell by cell, and appends the plan's verdict-history rows; on a miss, the batch is redone at the standard tier.

Record per company in `status.csv` (S14 done) and `progress.md`: the Data row written (or "hold, history only"), data flags written, pending yes/no.
